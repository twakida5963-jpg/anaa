# ANA特典航空券 空席監視 — Macクラウドビルド版

目的は「MacにPythonやターミナルを入れず、最終的に.appをダブルクリックして使う」ことです。

## この版でできること
- SwiftUIのMacアプリ
- ANA公式サイトをアプリ内ブラウザで開く
- ANAパスワードを設定ファイルへ保存しない
- 監視条件の複数登録
- 出発日の範囲指定
- 監視間隔10分の状態表示
- ntfyのiPhone通知トピック保持
- GitHub ActionsでmacOS上の.appを自動生成

## 重要
このプロジェクトは「Macアプリをクラウド上でビルドするところ」までを自動化しています。
ANAのログイン後に特典航空券の検索・空席数を自動判定する本体は、現行ANAサイトの実機確認後に接続する必要があります。
